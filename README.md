# TaskFlow – Sistema de Gerenciamento de Tarefas Acadêmicas

## Projeto
O TaskFlow é um sistema de gerenciamento de tarefas acadêmicas desenvolvido para organizar atividades, prazos e responsáveis em um ambiente centralizado.

## Integrantes
- MATEUS FREIRE PATRIOTA
- CAIO HENRIQUE HAHNEMANN DE SOUZA KRAETZE

## Funcionalidades
- Cadastro e autenticação de usuários
- Gerenciamento de quadros e tarefas
- Definição de prazos e responsáveis
- Acompanhamento do andamento das atividades
- Visualização de relatórios básicos

## Requisitos não funcionais
- Interface responsiva
- Carregamento da tela principal em até 2 segundos
- Proteção das senhas por criptografia

## Iteração 1 – Fase de Construção
Nesta iteração são considerados o guia do usuário, o diagrama de implantação e a demonstração da aplicação em funcionamento.

## Estrutura de implantação
A aplicação é organizada em dispositivo do usuário, servidor da aplicação e servidor de banco de dados, com comunicação entre os componentes por rede.
